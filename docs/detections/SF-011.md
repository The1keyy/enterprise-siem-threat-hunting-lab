# SF-011 — SMB / admin-share remote logon

## Objective

Alert when a lab account accesses an admin share, and keep a lower alert for IPC$ and for a type-3 network logon. The technique is `T1021.002` only.

## ATT&CK

`T1021.002` SMB / Windows Admin Shares. Lateral Movement.

## Telemetry

- Audit File Share, Success, writes 5140.
- Audit Detailed File Share, Success, writes 5145.
- Audit Logon, Success, writes 4624 type 3.

Collect all three on DC01 and WS01. The planned simulation is `net use` of `\\DC01\C$` from a lab VM.

Chain for the share rules: 60000 → 60001 → 60103. Stock 67017 is 5140, level 3, and it already drops IPC$ and NetLogon. `shareName` is the field it checks. `5145` is not named in this ruleset. `relativeTargetName` is not a field check and is not used. The type-3 rule chains on 60106, the same 4624 parent as SF-010.

## Logic

4624 and 5140 are different events. One Wazuh rule cannot require both without `frequency`, and this image has no frequency rule that also contains a `<field>` check. These rules do not wait for each other. A same-IP join is Step 14.

Rule 100510, level 12, matches 5140 or 5145 when `shareName` ends in `\ADMIN$` or `\C$`, or is exactly `ADMIN$`. Level 12 is high (ADR 0004) and is above 67017, so an admin-share access is labeled SF-011. ADMIN$ and C$ are the lateral-movement shares. The library row is high because this is that behavior.

Rule 100511, level 4, matches IPC$ only. Level 4 is low. IPC$ is normal domain named-pipe traffic. Treating it as high would page on ordinary logons. It stays in the file as context.

Rule 100512, level 5, matches 4624 type 3. Level 5 is low and is below stock 92652 (level 6), so an NTLM remote logon is not relabeled as SF-011. Type 3 alone is every network logon, including file servers and scheduled tasks. It is not the high alert.

Why path-based and SID-style exclusions, not content: a share name the attacker can type into a command is not the exclusion. The exclusion is the account form and the source address.

## Exclusions

- `subjectUserName` ending in `$` on 100510 and 100511. `targetUserName` ending in `$` on 100512.
- `ipAddress` exactly `10.10.10.1` on all three. That is the lab host adapter. WS01 `10.10.10.20` is the planned simulation source and is not excluded.
- No agent-path exclusion. These events do not use `image`.

## Validation procedure

Mac: `make logtest ID=SF-011` prints LIMITED.

Lab, Step 13, not run. **REQUIRES WINDOWS VALIDATION.**

1. Snapshot WS01 and DC01 first.
2. Inside `sentinelforge.lab`, map `\\DC01\C$` from WS01 with an `sf-test-*` account.
3. Remove the mapped drive and log off. Delete leftover `sf-test-*` accounts. Restore the snapshot if the host changed.

## Expected result

Rule 100510, level 12, for `\\*\C$` or `\\*\ADMIN$`. Rule 100511, level 4, for `\\*\IPC$`. Rule 100512, level 5, for a type-3 4624. MITRE `T1021.002`.

A 5142 share-create does not fire 100510. A machine account does not. Source `10.10.10.1` does not. IPC$ does not fire 100510.

## Observed result

`NOT YET VALIDATED`.

## False positives

An administrator maps `\\DC01\C$` during lab setup. IPC$ alerts at level 4 will be common on a domain controller. Type-3 alerts at level 5 will be common for any network logon.

## Tuning

After a lab baseline, drop 100511 if IPC$ has no investigative value. Do not raise IPC$ to the admin-share level to quiet the queue. Do not match a share name as a substring of the command line. If 5145 is the only event the audit policy writes, 100510 already accepts it. Confirm which ID DC01 emits.

## Investigation

1. Read `shareName`, `subjectUserName`, `ipAddress`, and the computer.
2. For a type-3 alert, read `targetUserName` and `logonType`, then look for a 5140 or 5145 from the same address. That join is manual until Step 14.
3. Confirm the account is `sf-test-*` and that you mapped the share.
4. If the source is unexpected, keep the address and remove the drive.

## Remediation

Remove the mapped drive and log off the session. Delete leftover `sf-test-*` accounts. Restore the snapshot if you are not sure what changed. This is a lab action, not an automated response.
