# SF-005 — Encoded PowerShell process

## Objective

Alert when Sysmon logs process creation for `powershell.exe` or `pwsh.exe` and the command line carries `-EncodedCommand`, `-enc`, or `-e` plus a base64 token. The technique on this alert is `T1059.001` only.

## ATT&CK

`T1059.001` PowerShell. Execution.

## Telemetry

Sysmon operational event 1 on WS01. The fields are `win.eventdata.image`, `win.eventdata.commandLine`, and `win.eventdata.parentImage`.

Chain: 60000 → 60004 (Sysmon channel) → 61600 (informational) → 61603 (event ID 1). File `0595-win-sysmon_rules.xml`. The content rules live in `0800-sysmon_id_1.xml` and use `(?i)` pcre2.

Security 4688 is not this rule. The only 4688 rule in this image is 67027 in `0955-WEF-baseline_rules.xml`. It is level 3, "A process was created," and it does not read `commandLine`. Command-line auditing for 4688 stays a lab check. It is not assumed here.

## Logic

One process creation is enough.

The image must end in `\powershell.exe` or `\pwsh.exe`. The command line must contain `-EncodedCommand`, `-enc`, or `-e`, then whitespace, then at least 20 characters from the base64 alphabet. `-e hi` and `-e Bypass` do not qualify. `-Command` does not qualify. `-ExecutionPolicy` and `-ep` do not qualify, because the character after `-e` is not whitespace.

Exclusions are anchored paths, not command-line text. The command line is chosen by whoever starts the process, so a marker typed into it would hide a real alert. The exclusion is the image or parent image equal to the Wazuh agent executable.

Stock rule 92057 is level 12, MITRE `T1059.001`. It requires a `powershell.exe` parent and the word `powershell.exe` in the command line. Its flag expression uses a word boundary, so the common form `-enc` is not in that list as its own token. It does not mention `pwsh.exe`. This image has no `pwsh` rule at all.

Stock 92071 is also level 12 but only after WMI (92070), and it adds MITRE `T1047`.

Rule 100210 is level 13, still high (ADR 0004). It is one above 92057 so this description wins when both match. MITRE stays `T1059.001` only.

## Exclusions

- `image` or `parentImage` equal to `C:\Program Files (x86)\ossec-agent\wazuh-agent.exe`, case-insensitive, one or two backslashes between segments.
- Nothing else. The command line is not an exclusion.

The 4.14.9 Windows agent page says that directory is the default (MSI `wazuh-agent-4.14.9-1.msi`). VERIFY: `wazuh-agent.exe` is the process name in 4.14.1 and 4.14.3 reports at that path. It is not confirmed on a 4.14.9 install in this lab. A custom install directory is not excluded. If the lab path differs, the alert still fires.

## Validation procedure

Mac: `make logtest ID=SF-005` prints LIMITED.

Lab, Step 13, not run. **REQUIRES WINDOWS VALIDATION.**

1. Snapshot WS01 first.
2. On WS01, run `scripts/powershell/simulations/SF-005-EncodedCommand.ps1`. The encoded command is `Write-Output "sentinelforge-lab"`. It does not download AtomicTestHarnesses. Stay inside `sentinelforge.lab`.
3. Run `SF-005-EncodedCommand-Cleanup.ps1`. The child process has already exited. Restore the snapshot if the host changed.

The lab-reference token `U1lOVEhFVElDIFRFU1QgSU5QVVQ=` is the words `SYNTHETIC TEST INPUT`. It is 28 characters. It is not a payload.

## Expected result

Rule 100210, level 13, description starting with `SF-005`, MITRE `T1059.001` only.

`powershell.exe -e hi` does not fire it. `powershell.exe -e Bypass` does not. `powershell.exe -ExecutionPolicy Bypass` and `powershell.exe -ep Bypass` do not. `powershell.exe -Command Write-Output hello` does not. The same encoded command still fires when the command line also contains `sentinelforge-setup`. It does not fire when `parentImage` is the anchored agent path above.

## False positives

A software installer or management agent launches PowerShell with an encoded command. Those are real on a workstation. Only the default Wazuh agent executable path is excluded. Other management agents, and a Wazuh agent installed somewhere else, are not excluded.

## Tuning

The base64 minimum is 20. Do not drop the token requirement, or every `-e` flag becomes an alert. Do not exclude a word inside `commandLine`. Do not add `T1047`.

## Investigation

1. Read the image, command line, and parent image.
2. Confirm the host is WS01 and that you started the Atomic test.
3. If the parent is not yours, record the parent path and end the process.

## Remediation

End the process on WS01. Restore the snapshot if the command's effect is unclear.
