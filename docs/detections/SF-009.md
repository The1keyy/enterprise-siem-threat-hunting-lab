# SF-009 — New local or domain user

## Objective

Alert when Security 4720 records a new user account. On its own this is medium. It becomes part of the account-manipulation story when SF-007 or SF-008 follows. Joining those alerts is Step 14. The technique is `T1136.001`.

## ATT&CK

`T1136.001` Local Account. Persistence.

The roadmap row is a new local or domain user, and the event is 4720. A 4720 on WS01 is a local user. A 4720 on DC01 is a domain user. The rule does not filter the computer name.

## Telemetry

Audit User Account Management, Success.

Chain: 60000 → 60001 → 60103 → 60109. Rule 60109 is level 8 and matches 4720 or 4722, MITRE `T1098`. Rule 100320 adds `^4720$` and MITRE `T1136.001`.

Computer account creation is 4741, not this rule. `0580-win-security_rules.xml` matches 4741 on a different parent.

## Logic

One create is enough.

Level 10 is medium (ADR 0004). It is above 60109 so a create is labeled SF-009, and it stays medium. It is below SF-007 (13) and SF-008 (15 and 13). Enabling an existing account (4722) does not fire it.

The account name is not the match. `sf-test-user` and any other new user name both fire.

Exclusions use anchored SIDs, not a name. This rule has no exclusion.

## Exclusions

None.

## False positives

An administrator creates `sf-test-user` on DC01, or a local user on WS01. Both are real 4720 events.

## Tuning

Do not drop this below level 10 or stock 60109 (level 8, MITRE `T1098`) is the alert that remains. Do not exclude an account by its name. Step 14 is where a 4720 followed by SF-007 or SF-008 becomes one incident.

## Investigation

1. Read `targetUserName`, `targetSid`, `targetDomainName`, and `subjectUserName`.
2. See whether SF-007 or SF-008 fired for the same member afterward. That join is not automatic yet.
3. Confirm the computer is WS01 or DC01 and that you started the Atomic test.
4. If the account is unexpected, keep the SID and disable the account.

## Remediation

Delete the `sf-test-*` account. Restore the snapshot if you are not sure what changed. This is a lab action, not an automated response.
